How steepest descent works

To minimise a differentiable function f(x), steepest descent moves at each step in the direction in which f decreases fastest. That direction is the negative gradient, −∇f(x).

xk+1 = xk − αk ∇f(xk)
  1. Choose a starting point x0 and a tolerance ε.
  2. Compute the gradient gk = ∇f(xk). If ‖gk‖ < ε, stop: xk is (approximately) a stationary point.
  3. Set the search direction dk = −gk.
  4. Choose a step size αk > 0:
    • Exact line search: αk = argminα>0 f(xk + α dk). Here it is found numerically with golden-section search.
    • Armijo backtracking: start at α = 1 and halve α until f(xk + α dk) ≤ f(xk) − c·α‖gk‖², with c = 10⁻⁴.
    • Fixed step: the same α every time. If α is too large the iterates overshoot or diverge; if it is too small, progress is slow.
  5. Update xk+1 = xk + αk dk and repeat from step 2.

Things to try: On the circular bowl, exact line search reaches the minimum in one step. On the elongated bowl the path zig-zags, and with exact line search every step is perpendicular to the previous one. This is the classic weakness of steepest descent on ill-conditioned problems. On Rosenbrock, the iterates crawl slowly along the curved valley. On Himmelblau, different starting points lead to different minima.
